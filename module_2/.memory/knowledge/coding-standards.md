\# Coding and Project Standards



\*\*Owner:\*\* Project maintainer

\*\*Last reviewed:\*\* August 7, 2026

\*\*Next review:\*\* November 5, 2026



\## Standards



1\. Make only changes that are directly related to the current assignment or requested task.



2\. Do not modify unrelated project files.



3\. Before changing files, inspect the existing project structure and relevant documentation.



4\. Keep changes small, clear, and easy to review.



5\. Do not store passwords, API keys, credentials, personal data, or other sensitive information in project memory.



6\. Before committing changes, review `git status` and confirm that only intended files are included.



7\. Do not overwrite human-maintained Knowledge Files. Files in `.memory/knowledge/` are read-only for the agent.



\## Ownership



These standards are maintained by the human project owner. Claude Code may read and follow them but must not edit them.



\## Review Policy



Review these standards every 90 days or whenever the project's development or safety requirements change.
