\# Reference Memory Index



\## Purpose



This index lists larger or less frequently needed reference documents that Claude Code can consult when additional project background is required.



\## Current References



No indexed reference documents are currently required for this project.



The existing repository documentation is sufficient for the current Module 2 workflow, so duplicating those documents in the reference memory layer would add unnecessary information.



\## When to Add a Reference



Add a reference document when the project contains large or specialized background material that:



\* is useful across multiple sessions;

\* is not needed during every session;

\* cannot be understood reliably from the normal project files alone; and

\* would use unnecessary context if loaded automatically at startup.



Reference documents are human-maintained and should be treated as read-only by the agent.
